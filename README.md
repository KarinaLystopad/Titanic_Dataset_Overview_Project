# Проєкт: Titanic Dataset Overview Project

## Опис
У цьому репозиторії зберігаються результати виконання проєкту з аналізу історичних даних про пасажирів корабля "Титанік" (датасет із бібліотеки Seaborn). Для роботи використано бібліотеки **NumPy**, **Pandas**, **Matplotlib** та **Seaborn**.

## Мій внесок
У межах проєкту я:
- Завантажувала та перевіряла коректність датасету.
- Аналізувала типи стовпців та виконувала їх перетворення.
- Створювала новий стовпчик `relatives` для підрахунку кількості родичів на борту.
- Формувала булеву ознаку `alone` та перевіряла її відповідність.
- Виконувала очищення датасету (дроп стовпців, заповнення пропусків медіаною).
- Проводила групування та агрегацію даних для аналізу кількості родичів.
- Категоризувала значення у стовпці `relatives_category` (наприклад, "above 5").
- Виконувала відсотковий аналіз пасажирів із великою кількістю родичів за містами посадки.
- Створювала категорії віку та аналізувала смертність у різних вікових групах.
- Використовувала візуалізацію для представлення результатів.
